📝 更新日志
v3.2.0 2026-10
  • 论坛分页：首屏只加载 20 条，底部"加载更多"翻页，突破 100 条上限
  • 骨架屏：论坛、文件、成员墙加载时显示灰色占位卡片，不再只有"加载中…"
v3.1.0 2026-10
  • 帖子图片：发帖可附带最多 9 张图片，点击可全屏预览
  • @提及：输入 @ 弹出成员列表，被提及者收到通知
  • 数据统计：班委/老师可查看班级活跃度、发帖排行、文件排行、活动参与率
v3.0.0 2026-10
  • 公告系统：班委/老师可发布公告，支持置顶、编辑、删除
  • 班级相册：照片墙，支持批量上传、点击预览、管理员删除
  • 顶栏重设计：主链接保留 6 项，管理项收进下拉菜单，个人管理移回顶栏
v2.5.0 2026-10
  • 通知中心：申请 / 批准 / 拒绝通知，顶栏红点徽章
  • 退出班级：个人中心可退出当前班级
  • 文件分类：上传时填文件夹，顶部按文件夹筛选
  • 帖子搜索：论坛顶部搜索框，高亮匹配
  • 头像墙：班级事务页显示成员头像
  • 删除班级：创建者（老师）可删除班级
v2.3.0 2026-10
  • 班级广场：老师可创建班级；学生/班委可申请加入
  • 申请审批：班委审批学生申请，老师审批所有申请
  • 三级论坛：本班 / 年级 / 公共 论坛切换
  • 嵌套回复：支持楼中楼
v2.0.0 2026-10
  • 活动统计：时间投票（When2meet 风格网格）+ 接龙
  • 个人日程：日程 + DDL，首页红点提醒
  • 顶栏导航：新增"活动统计"和"个人管理"入口
v1.0.0 2026-10
  • 账号系统：邮箱注册/登录，三类身份（学生 / 班委 / 老师）
  • 班级事务：三种视图（时间轴 / 时间表 / 列表），管理员可编辑
  • 班级论坛：发帖 / 回复 / 点赞 / 实时同步
  • 班级文件：拖拽上传，全班可看
  • 个人中心：头像 / 昵称 / 密码 / 注销
  • 用户管理：管理员可查看成员、重置密码、修改身份
