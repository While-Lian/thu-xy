📝 更新日志
v3.6.0 2026-10
  • 存储优化：图片上传全面支持前端自动压缩（头像 512p，图片 1024p），极大节省服务器空间
  • 空间清理：删帖/换头像时自动连带清理云端旧图片，杜绝“幽灵文件”白占空间
  • 上传限制：班级文件限制为 15MB 以内，并禁止上传视频和压缩包，保障网盘容量
  • 懒加载：全站图片加入懒加载机制，流量消耗大幅降低，网速更丝滑
  • 个人名片：在个人中心可设置微信号和手机号，点击班级成员头像即可查看名片
  • 一键日程：班级事务新增“📅”按钮，点击即可将活动一键存入个人日程
  • 日历导出：个人管理支持一键导出 ICS 日历文件，轻松同步至手机自带日历
  • 体验修复：彻底修复了首次进入某些页面会卡在“加载中”的时序 Bug
v3.2.0 2026-10
  • 论坛分页：首屏只加载 20 条，底部“加载更多”翻页
  • 骨架屏：论坛、文件、成员墙加载时显示灰色占位卡片
v3.1.0 2026-10
  • 帖子图片：发帖可附带最多 9 张图片，点击全屏预览
  • @提及：输入 @ 弹出成员列表，被提及者收到通知
  • 数据统计：班委/老师可查看班级活跃度、发帖排行、活动参与率
v3.0.0 2026-10
  • 公告系统：发布公告，支持置顶、编辑、删除
  • 班级相册：照片墙，支持批量上传和预览
  • 顶栏重设计：主链接保留，管理项收进下拉菜单，支持移动端底部导航和侧边抽屉
v2.5.0 2026-10
  • 通知中心：申请 / 批准 / 拒绝通知，顶栏红点徽章
  • 班级广场：创建班级、申请加入、审批、退出、删除班级
  • 文件分类：上传时填文件夹，顶部按文件夹筛选
  • 帖子搜索 / 嵌套回复：论坛支持关键词高亮和楼中楼
v2.0.0 2026-10
  • 活动统计：时间投票（When2meet 风格网格）+ 接龙
  • 个人日程：日程 + DDL，首页红点提醒
v1.0.0 2026-10
  • 账号系统：邮箱注册/登录，三类身份（学生 / 班委 / 老师）
  • 班级事务：三种视图，管理员可编辑
  • 班级论坛：发帖 / 回复 / 点赞 / 实时同步
  • 班级文件：拖拽上传，全班可看
  • 个人中心：头像 / 昵称 / 密码 / 注销
