📝 更新日志
v5.1.0 2026-10
  • 作业收集箱：班委可发布收集任务，同学一键上传文件，支持进度统计与未交名单导出，彻底告别群聊刷屏
  • 随机抽签转盘：内置单人抽取与随机分组功能，支持大屏投影，班会破冰、课堂点名神器
  • 顶栏 UI 重构：将低频功能（相册、班费、意见箱等）收纳至“班级工具”下拉菜单，解决功能过多导致的重叠问题
  • 体验优化：修复了切换班级后部分组件不刷新的 Bug，补齐了 Markdown 错位、样式丢失等历史遗留问题
v5.0.0 2026-10
  • 班费收支账本：公开透明的班级财务模块，班委可记账，自动计算余额，流水明细一目了然
  • 经验与等级系统：发帖、评论、接龙均可获得 EXP（经验值），打造从“初入行健”到“镇班之宝”的养成体验
  • 匿名意见箱：同学可发送完全匿名的反馈，班委可在后台查阅并标记“已处理”
v4.0.0 2026-10
  • Markdown 富文本：论坛全面支持 Markdown 语法，发长文、代码块、加粗排版更美观
  • 匿名树洞：发帖时可选“匿名发布”，系统自动隐藏头像与真实昵称
  • 全局搜索：支持 `Ctrl + K` 快捷键，一键跨模块搜索公告、帖子、评论和文件
  • 暗黑模式：适配夜间使用，保护视力，自动记忆偏好
  • PWA 桌面通知：切到后台也能收到班级新消息的系统级弹窗（需授权）
v3.8.0 2026-10
  • 多班级管理系统：老师/辅导员可同时管理多个班级，在顶栏无缝一键切换
  • 权限体系重构：确立“老师 > 班委 > 同学”的层级，老师拥有全局管理权，班委仅可管理本班学生
  • 数据级联：修复了老师切换班级后，任务、审批、统计等数据不跟随切换的底层漏洞
v1.0.0 - v3.0.0 历史版本
  • 基础架构：从单机 localStorage 升级为 Supabase 云端实时协同
  • 内容模块：上线班级事务（三视图）、班级论坛（楼中楼）、班级文件（分类上传）
  • 活动工具：支持活动报名、When2meet 风格时间投票、接龙、个人 DDL 日程
  • 系统安全：接入邮箱注册、登录守卫、密码重置、头像裁剪与云端空间清理
