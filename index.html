📝 更新日志
v2.0.0 2026-10
  • 活动统计：新增时间投票（When2meet 风格网格），管理员发布时段，同学点击/拖动选择空闲时间，颜色深浅显示人数
  • 接龙功能：一键参与/取消，支持截止时间、人数上限、备注，班委可一键复制名单
  • 个人日程：在"个人管理"中添加日程与 DDL，仅本人可见
  • 首页提醒：DDL 按截止临近程度变色（逾期深红、今天红、3 天橙、7 天黄），点击"已完成"从首页消失
  • 顶栏导航：新增"活动统计"和"个人管理"入口
v1.0.0 2026-10
  • 账号系统：邮箱注册/登录，双角色（同学 / 管理员），通过邀请码区分
  • 班级事务：三种视图（时间轴 / 时间表 / 列表），管理员可编辑，普通同学只读
  • 班级论坛：发帖 / 回复 / 点赞 / 实时同步，支持删帖（管理员可删所有）
  • 班级文件：拖拽上传，全班可看，管理员可上传/删除
  • 个人中心：更换头像、修改昵称、修改密码、注销账号
  • 用户管理：管理员可查看本班成员、重置忘记密码同学的密码
  • 界面重构：全新 UI，清华紫主题，响应式设计
v0.x 早期版本
  • 基础的班级事务管理（密码门禁）
  • 三种视图：时间轴 / 时间表 / 列表
  • 本地 + Supabase 双存储
